\section{Classic Protocols to Handle Resource Sharing}
\subsection{Priority Inheritance Protocol (PIP)}
    \begin{itemize}
        \item Idea: Low-priority task inherits the priority of blocked high-priority task.
        \item Pro: Simple, reduces blocking.
        \item Con: Can cause chained blocking.
        \item Diagram: Show a task getting temporary high priority.
    \end{itemize}
\subsection{Priority Ceiling Protocol (PCP)}
    \begin{itemize}
        \item Each resource has a ceiling priority.
        \item Tasks must lock resources carefully based on ceilings.
        \item Prevents deadlocks.
        \item Pro: Bounded blocking.
        \item Include a resource-access matrix or state machine.
    \end{itemize}
\subsection{Stack Resource Policy (SRP)}
    \begin{itemize}
        \item Preemption controlled based on the resource ceiling.
        \item Works with EDF scheduling.
        \item Prevents deadlocks.
        \item Pros: Avoids runtime priority changes.
        \item Used in Real-Time Java, OSEK, and automotive systems.
    \end{itemize}
