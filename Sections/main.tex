\begin{abstract}
In resource constrained environment of embedded electronic, resource allocation is critical consideration. For tasks to be completed efficiently and within time frame, protocols are to be followed to allocate resources sufficiently. We know that, in hard real time systems, deadline miss can pose life threatening consequences. The operating system of any real time system follows these protocols to invoke its kernel to allocate resources on-demand for the executable processes. The seminar paper is a discussion on how the resource protocols are followed inside the OS. 
\end{abstract}
